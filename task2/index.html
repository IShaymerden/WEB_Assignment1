Welcome to Task 2

This webpage demonstrates a simple two-column layout created using HTML div elements and CSS float properties. The sidebar is positioned on the left, while the main content is displayed on the right.

HTML Basics

HTML is used to create the structure of a webpage. It defines headings, paragraphs, links, lists, images and other elements.

CSS Styling

CSS is used to control the appearance of HTML elements. It allows developers to change colors, fonts, spacing, borders and page layouts.

Web Layout

A webpage layout determines how different sections are arranged. This example uses the CSS float property instead of Flexbox or Grid.
