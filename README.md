
# Web Assignment 1 - HTML & CSS Basics

## Project Description

This project was created for the WEB Technologies course at Astana IT University.

The purpose of this assignment is to demonstrate basic HTML and CSS skills, including webpage structure, styling, navigation, positioning, tables, and forms.

The project contains four individual tasks.

## Completed Tasks

### Task 1 - Personal Webpage

A personal webpage containing:
- Personal information and profile card
- Headings, paragraphs, and lists
- Images and navigation links
- CSS styling and responsive design

### Task 2 - Simple Webpage Layout

A webpage layout created using HTML div elements and CSS float properties.

The page includes:
- Header and navigation bar
- Left sidebar menu
- Main content section
- Footer

Flexbox and Grid are not used in this task.

### Task 3 - Tribute Page

A tribute page dedicated to Alan Turing.

The page includes:
- Biography and portrait
- Important events in his life
- Key contributions to computer science
- External links and a Learn More button
- Google Fonts and CSS styling

### Task 4 - CSS Table and Form

A webpage demonstrating HTML tables and forms.

The page includes:
- Student grades table
- Alternating row colors and highlighted rows
- Merged table cells using colspan
- Feedback form with text fields, email, dropdown, radio buttons, and textarea
- Styled submit button

## Technologies Used

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the main `index.html` file using Live Server or a web browser.
4. Use the navigation bar to switch between the assignment tasks.
